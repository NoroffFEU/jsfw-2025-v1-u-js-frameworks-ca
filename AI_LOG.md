# AI Usage Log

I used ChatGPT during the development of the Blend Shop project as a
debugging and learning aid. I remained responsible for understanding,
testing and integrating the solutions into my project.

## 4–8 August 2026 — Product API and project structure

**Tool used:** ChatGPT

**Purpose:** Understanding the assignment requirements and planning the
initial project structure.

**What I used AI for:** I asked for help understanding how to begin the
online shop assignment. ChatGPT explained the requirement to use the
`GET /online-shop` API endpoint and helped identify the TypeScript types
needed for the API response, including products, images and reviews.

The guidance also explained how to separate product display into a
reusable `ProductCard` component instead of putting all product display
logic directly into the homepage.

**Outcome:** I used this guidance to plan the initial application
structure and implement the product API integration. I created
TypeScript types for the API data, fetched products and displayed them
using reusable product cards. This provided the foundation for the later
product details, search, sorting and shopping cart features.

**My responsibility:** I implemented and tested the functionality in my
own project and adapted the suggested structure to fit my application.
